## Black Forever terrain and trees: the capture harness never ran the lighting pass

`world_object_census.gd` skipped `preview_world_lighting`, so `scene_light` was unset and both the terrain and M2 materials read ambient 0: 2980 went from 75.8% of pixels below 12/255 to 0.0%, 2959 from 22.7% to 0.2%, with object counts unchanged. The terrain-texture census (185 tex0 BLPs, 184 unreceipted, published as 182 receipts) closed a coverage gap but did not change the render, because terrain BLPs resolve through `data/textures/<fdid>.blp`, not through model receipts. Five Forever maps still stream no tiles: `world_attached: false` with no parsed tiles and no failures.

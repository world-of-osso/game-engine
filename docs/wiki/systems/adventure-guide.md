## Catalog and native host

`scripts/adventure_guide_import.py` decodes the pinned local69933 Journal WDC5 layouts into `data/cache/adventure_guide.sqlite`, preserving hierarchy, difficulty relations and readable/unreadable counts. Pinned Item/ItemSparse, ChrSpecialization, ChrClasses, GlobalStrings, Difficulty and MapDifficulty CSVs supply metadata. Item compatibility follows TrinityCore a352b1fa `ObjectMgr::ItemSpecStats/LoadItemTemplates`: overrides replace general type/stat matching; no authored specialization means unrestricted. Gem relic traits remain unmodeled without GemProperties.

The core Catalog loads immutable rows; the UI View owns selection, expandable sections, filters and global search. MapDifficulty selects genuine legacy difficulties (Molten Core9), rather than assuming modern raid14; JournalEncounterXDifficulty further restricts boss lists and choices (Vanessa is Heroic-only). Loot menus group robes with Chest and weapon types into Retail MainHand/OffHand categories. A collapsed ability parent remains traversable on Overview when that parent has no visible control there. Item Sets build viewport-intersecting compact atlas rows with authored icons, quality colors, specific-spec filters and shared Retail squished item levels. Their hover reuses the item/Shift comparison tooltip and appends pinned ItemSetSpell thresholds, equipped membership and explicit unsupported eligibility notices. Class/spec changes reset the pixel offset. Tutorials uses Retail's authored RPE Catch Up Experience strings/art, not invented journal help; the realm lacks the start service.

The native host opens from the existing J binding, micro menu and active boss-frame right-click. First-open requests stay queued behind the existing asynchronous spell catalog, with explicit loading chrome and no raw-token fallback. Its pointer handler routes real wheel/stepper/thumb input through RegistryUi; registry enumeration alone does not wire scrolling. All four Journal pixel lists use Retail ScrollFrameTemplate's30-pixel pan extent, not the native default one-row/one-pixel step. Opening during an active ENCOUNTER_START selects that encounter and its authoritative difficulty. Starts received while the Guide is already visible queue the same source ID/difficulty until catalog readiness; starts received while closed do not open it. Encounter selection clears old search, menus and collapsed sections. Raid-entry's InstanceInfo supplies saved status, completed-mask count and snapshot-relative reset time. A detached creature preview hosts the selected JournalEncounterCreature display. `adventure_guide_state` exposes read-only displayed selection/filter/model readiness for native automation.

## Transparent preview additive coverage

Ozruk36475's authored Add batches0/3 use chalk415840 with full-opacity black texels. Their world material correctly adds zero light for black; the transparent preview target accumulated coverage instead, so its TextureRect obscured the Guide backdrop. This was a renderer/compositing failure, not missing texture data or particles (the source model has none).

The M2 material factory publishes preview-only Add/NoAlphaAdd shader metadata. Those variants write additive RGB with zero coverage using premultiplied blending; Add retains authored source opacity, NoAlphaAdd ignores it. `bind_preview_light` selects that variant only for model previews, and the shared model-view TextureRect uses premultiplied compositing. Authored world shaders and their blend/depth state remain unchanged. No black-texel discard, texture replacement or alpha threshold masks the problem.

`godot/tests/m2_preview_blend_pixels.gd` reproduces the real black texel boundary and checks five GPU outputs: backdrop preserved, positive half-opacity Add matches world RGB, its light remains over the backdrop, ordinary mix coverage and actual opaque-batch coverage. Root RED was RT(0,0,0,1)/black UI; GREEN is RTcoverage0/backdrop(.251,.349,.451). Positive RGB(.4196,.5333,.3961) remains and composes(.6706,.8824,.8471). NoAlphaAdd's generated branch is implemented but not certified by a sourced model case in this gate.

Engine8966a5080/servercec3f237/protocol7062a60 private5771 Model-page captures in both skins remove the black cards while retaining the authored effect. Requested PNGs `modern-ozruk-additive-compositing-fixed.png` and `forever-ozruk-additive-compositing-fixed.png` are inspected.

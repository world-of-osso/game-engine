Retail Mainline `Blizzard_EncounterTimeline`, `Blizzard_EncounterWarnings` and generated EncounterTimeline/Constants/EncounterWarnings APIs define the feature. Forever changes art, not elements or behavior.

## Contract
- Explicit current-Retail boss-mod-Lua-backed scripted encounters project their actual selected EventMap requests, including repeat/cancel changes; bars match the server's queued cast requests, not an independent imported clock or a client estimate. Kokia, Melidrussa, Kyrioss, Doragosa, Azureblade and Umbrelskul opt in. Other encounters retain sourced addon schedules; TDB SmartAI-only timers do not supply alert clocks without an explicit sourced mapping. No fabricated mechanics. Unsupported addon conditions remain reported gaps.
- Actual accepted casts send sourced addon severity and fully rendered enUS warning text, including authored counts; the client displays that text verbatim. Missing dynamic target/native-message text remains a named gap, not a generic replacement. Scripted labels use shipped native SpellName data; imported warning substitutions retain pinned SpellName12.1.0.69933. Imported phase changes display numeric phase warnings without invented phase names. Events share the reliable ordered encounter lifecycle channel and are restricted to the dungeon copy.
- Timer snapshots replace one caster's timers; empty snapshots cancel. UTC sample timestamps (the existing group-countdown clock domain) preserve the selected deadlines across reliable delivery delay; receipt age is subtracted, never restarted as a fresh timer. End, Start, loading/disconnect/reset clear timers and warnings. Countdown reaching zero never creates a warning: only a received real cast does.
- Bars show spell icon/name and remaining time, nearest-first, at most ten, with five-second imminent highlighting. Timer bars use EncounterTimelineTimerEventTemplate's textured background, cropped remaining-time fill and additive source-sized spark; the spark follows the fill edge and hides at zero. XML/Lua anchors determine the26px bar,36px background overhang and34px icon/row. Track view moves icons toward zero. Both use the same scheduler data and settings.
- Warnings replace the current line at their severity, display spell text and flanking icons, optionally play the cached Retail RaidBossEmote sound kit12197. Presentation hold3s is not an ability timer. Exact Retail severity→native API sound mapping is unavailable in cached Lua; do not claim that mapping.
- Interface settings persist timeline enable, Bars/Timeline view, warning enable and sound enable. Edit Mode moves EncounterTimeline and each of the three severity warning regions; settings/positions apply to both skins.

# Button Prompts

Use these as starting points for single generation runs.

## Regular Bronze

```text
Use case: stylized-concept
Asset type: fantasy MMO login button image
Primary request: single centered game login button asset
Style/medium: polished game UI art
Composition/framing: straight-on view, one button only, transparent background
Lighting/mood: warm bronze, controlled highlights, no fog
Color palette: dark bronze, walnut-brown, muted gold accents
Materials/textures: carved metal rim, restrained bevel, subtle aged wear
Constraints: no text, no icon, no watermark, no background scene, clean silhouette
Avoid: purple, glossy plastic, red lacquer, washed-out haze
```
